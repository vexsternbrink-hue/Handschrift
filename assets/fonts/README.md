# Demo-Schriften

Diese Schriften werden **nur** für die Demo-Nutzer (`demo`, `demo2`) verwendet, um
ein „ausgefülltes“ Template zu simulieren. Echte Nutzer lernen ihre eigene
Handschrift über das Foto des Templates – diese Schriften werden dafür nicht benötigt.
